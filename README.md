Entry for the make.fun bounty [Fortune Cookie Funnies for Engineers](https://make.fun/bounty/u-eager-stork-81-9647-fortune-cookie-funnies-for-866bde2a): the funniest one-line fortune cookie message for a software engineer.

## The fortune

> A bug you fixed last month will return, wearing a different stack trace, asking to be friends.

94 characters, one line.

## How to run

```sh
python3 main.py
```

It checks the fortune first (1-120 characters, not only whitespace, exactly
one line), then writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or
`/output/entry.txt` when that variable is unset), with no trailing newline.

Python 3 standard library only. No network, no external file reads, no
secrets.
